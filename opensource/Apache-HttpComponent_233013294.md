# Programming : Apache HttpComponent

Created by Dongwook Han, last modified on 5월 05, 2021

- Apache HttpClient → Apache HttpComponent로 버전업

- 세부 옵션을 builder로 설정(쿠키,권한,dns, socket, redirec)

- row level http 호출 가능

<!-- -->

- httpclient 생성 예제
```text
text
  HttpClient httpClient = HttpCliens.createDefault();
```
<!-- -->

- createDefault()
```java
java
  /**
   * Creates {@link CloseableHttpClient} instance with default
   * configuration.
   */
   public static CloseableHttpClient createDefault() {
    return HttpClientBuilder.create().build();
   }
```

- createMinimal()
```java
java
  /**
   * Creates {@link CloseableHttpClient} instance that implements
   * the most basic HTTP protocol support
   */
   public static CloseableHttpClient createMinimal() {
    return new MinimalHttpClient(new PoolingHttpClientConnectionManager());
   }
```
<!-- -->

- createDefault(), createMinimal() 은 모두 PoolingHttpClientConnectionManager() 를 사용

- createDefault() 계속 호출시 PoolingHttpClientConnectionManger 를 계속 생성함.

- internalHttpClient와 PoolingHttpClientConnectionManger는 @ThreadSafe 함

- 공유해서 사용하면 PoolingHttpClientConenctionManger 로 관리되는 instance를 같이 사용

- 필요시 다른 instance를 생성하여 사용 가능
```java
java
  @Bean
  public HttpClient httpClient {
    return HttpClient.createDefault();
  }

  @Bean
  public HttpClient PerformClient {
    PoolingHttpClientConenctionManager cm = new PoolingHttpClientConnectionManager()
        .setMaxTotal(300)
        .setDefaultmaxPerRoute(50);

    return HttpClients.custom().setConnectionManager(cm).build();
  }

  @Bean
  public HttpClient TimeClient {
    SoccketConfig sc = SocketConfig.custom()
    .setSoTimeout(2000)
    .setSoKeepAlive(true)
    .setTcpNodelay(true)
    .setSoReuseAddress(true)
    .build();
    return HttpClients.custom().setDefaultSocketConfig(sc).build();
  }
```
