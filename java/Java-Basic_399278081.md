# Java Basic

## 기본 타입
### 정수 타입
| 타입    | 저장 공간  | 범위                                                     |
| ----- | ------ | ------------------------------------------------------ |
| int   | 4 byte | -2,147,483,648 ~ 2,147,483,647                         |
| long  | 8 byte | -9,233,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |
| short | 2 byte | -32,768 ~ 32,767                                       |
| byte  | 1 byte | -128 ~ 127                                             |

- ex
	``` java
	long a = 400000L;
	byte b = (byte)127;

	```

### 부동소수점 타입
|타입|저장 공간| 범위|
|-----|----------|------|
|float| 4 byte| +-3.40282347E+38F|
|double| 8 byte| +-1.79769313486231570E+308|

- ex
	``` java
	float a = 3.14F;
	double b = 3.14;
	double c = 3.14D;
	```
- 기타 표현
	- 무한대를 나타내는 Double.POSITIVE_INFINITY
	- 음의 무한대는 나타내는 Double.NEGATIVE_INFITITY
	- 숫자가 아님 : Double.NaN
- 부동소수점을 16진수로 나타낼 수 있다. 
	- 0.0009765625 = 2^-10^ (2<sup>-10</sup>) 을 0x1.0p-10 으로 작성할 수 있음

### char 타입
- UTF-16 문자 인코딩의 코드 단위를 의미

### 큰 숫자
- 기본 정수 타입이나 부동 소수점 타입의 정밀도로 충분하지 않으면 java.math 패키지의 BigInteger, BigDecimal 클래스로 전환
	- BigInteger : 임의의 정밀도 정수 연산 구현
	- BigDecimal: 부동 소수점 수에 임의의 정밀도 부동소수점 연산 구현
	``` java
	BigInteger n = BigInteger.valueOf(876543271);
	BigInteger k = new BigInteger("87654321");
	
	BigDecimal.valueOf(n, e); // n * 10-e 반환
	```

- 객체에 연산자를 사용할 수 없기에 메서드 호출
	``` java
	BigInteger r = BigInteger.valueOf(5).multiply(n.add(k)); // k = 5 * (n + k)
	```

## 배열
- 각 primitive 타입 별로 대응하는 배열 타입을 생성
	``` java
	String[] names = new String[100];
	int[] cal = new int[10];
	```
- new 연산자로 배열 선언 시 기본값으로 채워짐
	- (char를 포함한) 숫자 타입의 배열은 0으로 설정
	- boolean 배열으 false
	- 객체 배열은 null
- 배열은 한번 생성하면 절대로 길이 변경 불가
- ArrayList 클래스는 배열의 한계를 극복하기 위해 내부에서 배열 관리
	``` java
	ArrayList<String> students = new ArrayList<>();
	students.add("student1");
	students.add("student2");
	
	students.remove(1);
	students.add(0, "student000");
	
	String first = students.get(0);
	
	```

- ArrayList 클래스는 제너릭 클래스
- 비교 연산자(\==, !=) 은 객체의 내용이 아닌 객체 참조를 비교
	``` java
	if (students.get(i) == students.get(j)) // 내용을 비교하는게 아닌 참조가 같은지 비교
	if (students.get(i).equals(students.get(j))) // 내용 비교시 equals 등 사용
	```

- 배열 변수는 복사할 수 있지만 두 변수가 같은 배열을 바라봄
	``` java
	int[] numbers = primes;  // numbers와 primes가 같은 배열을 바라봄
	
	```

- 별개의 배열을 가지도록 하려면 배열 사본을 만들어야 함.(Arrays.copOf() 사용)
	``` java
	int[] copiedPrimes = Arrays.copyOf(primes, primes.length);
	
	// ArrayList 
	ArrayList<String> people = students;
	people(0, "Mary");  // students.get(0) 도 Mary 임
	
	// ArrayList의 사본 생성 
	ArrayList<String> copiedStudents = new ArrayList<>(students); 
	```
