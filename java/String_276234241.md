# String

last modified on 3월 15, 2024

1.  String 클래스는 char\[\] + 메소드 결합한 것
    - String class = char\[\] + method
2.  String 클래스는 char[] + 메소드 결합한 것
    - String class = char[] + method
3.  String 클래스는 read only (재설정시 새로운 메모리 주소를 가리킴)
4.  주요 메서드
    - charAt(int index) : 문자열에서 해당 위치(index)에 있는 문자 반환
    - length()
    - substring(int from, int to)
    - equals(Object obj)
    - char\[\] toCharArray() : 문자열을 문자배열로 변환하여 반환
- 여러 문자열을 구분자로 구분하여 결합시 join 사용
	``` java
	String names = String.join(", ", "Peter", "Paul", "Mary"); // Peter, Paul, Mary
	```
- 문자열 분리 시 substring() 사용
- 문자열을 구분자로 분리 시 split() 사용
- 문자열 비교 시 equals() 
- Tip: 문자열을 리터럴 문자열과 비교할 때 리터럴 문자열을 앞쪽에 두는 게 좋다.
	``` java
	if ("World".equals(name))
	```
- 대소문자 구분 없이 비교 equalsIgnoreCase()
- 문자 정렬 시 오름차순 비교 compareTo
	``` java
	first.compareTo(second); // first 문자열이 second 문자열보다 오름차순으로 앞인지
	```
- 인식이 가능한 문자열을 정렬할 때는 Collator 객체를 사용
- 숫자 문자열 변환
	``` java
	int n = 42;
	String str = Integer.toString(n);
	
	str = Integer.toString(n, 2); // 두번째 파라미터를 받음 101010 (두번째 파라미터 2 ~ 36)
	
	n = Integer.parseInt(str); // n 을 101010 으로 설정
	
	n = Integer.parseInt(str, 2); // str를 기수 지정하여 반환 n은 42
	
	String str = Double.toString(3.14); // str을 "3.14"로 설정
	double x = Double.parseDouble("3.14");
	```

- 코드 포인트와 코드 유닛
	- java는 유니코드(16비트)를 수용
	- 이후, 유니코드로 커버하지 못한 문자까지 수용하기 위해 21비트로 전환
	- UTF-16은 길이가 가변적이고 하위 호환성을 지원하는 인코딩
	- 전통적인 유니코드 문자는 16비트 값 한 개로 나타내고 U+FFFF를 넘는 문자는 대용 문자라고 하는 코드 공간의 특별한 영역에서 가져온 16비트 값의 쌍으로 나타냄
		- A : \u0041, 수학기호 O : \ud835\udd46 
	- 따라서 자바 문자열은 유니코드 문자 또는 코드 포인트의 원래 시퀀스가 아닌 UTF-16 인코딩의 16비트 숫자인 코드 유닛의 시퀀스
	- 특수 문자나 중국어 같은 문자가 아닌 16비트 안에 포함되는 문자열의 값을 가져오려면 charAt() 을 사용하여 처리 가능
		``` java
		char ch = str.charAt(i); // i번째 문자의 코드값
		```

	- 문자열을 제대로 처리(중국어 문자, 특수 문자 포함해서 처리) 하려면 codePointAt()을 사용

		``` java
		int codePoint = str.codePointAt(Str.offsetByCodePoints(0, i)); // i번째 유니코드의 코드 포인트 얻기
		```
