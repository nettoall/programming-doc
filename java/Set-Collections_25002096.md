# Set Collections

Created by Dongwook Han on 8월 23, 2020

## 개념
- 저장 순서가 유지 안됨
- 객체 중복 저장 안 됨
- 종류 : HashSet, LinkedHashSet, TreeSet

- 공통 메소드

| 기능 | 메소드 | 설명 |
| --- | --- | --- |
| 객체 추가 | boolean add(E e) | 객체 저장 성공시 true |
| boolean containse(Object object) | 주어진 객체 저장 여부 |  |
| 객체검색 | isEmpty() | 컬렉션이 비어 있는지 여부 |
| Iterator(E> iterator | 저장된 객체를 한개씩 가져오는 반복자 |  |
| int size() | 전체 객체수 반환 |  |
| 객체 삭제 | void clear() | 모든 객체 삭제 |
| bollean remove(Object o) | 주어진 객체 삭제 |  |


## Set 반복자 사용 예제

Set\<String\> set = …;

Iterator\<String\> iterator = set.iterator();

- 메소드
|   **반환**       | **메소드**            | **설명**                               |
|----------|------------|-------------------------------|
| booelan  | hashNext() | 가져올 객체 여부              |
| E        | next()     | 컬렉션에서 하나의 객체 가져온 |
| void     | remove()   | Set컬렉션에서 객체 제거       |

- 예제
```java
Set<String> set = ...;
Iterator,String> iterator = set.iterator();

while(iterator.hasNext()){
  String str = iterator.next();
}
```

- for 문 예제
```java
Set<String> set = ...;
  for(String str: set){
  ....
  }
```

## HashSet

- 생성
```java
Set<E> set = new HashSet<E>();
```

- 객체 저장전 객체의 hashcode() 메소드로 hash 코드를 알아내 이미 저장된 객체들의 hash코드와 비교하여 중복시 저장 안 함.
