# Programming : Thread 개념과 이해

Created by Dongwook Han, last modified on 6월 16, 2023

# Thread 구조

- Process : 운영체제가 바라보는 일의 단위

- Thread : Process 내에서 다시 나누어지는 일의 단위

- Context Switch(문맥 교환)

  - 실행하고 있는 프로그램 혹은 Process를 교환

  - 실행에 이용되는 프로그램 카운터 스택 포인터, 레지스터 등의 내용으 ㄹ넣어 두고 거기까지 실행해간 Process 등의 실행에 필요한 정보를 보존하여 다음 실행을 시작하는 Proces 등의 정보를 이용할 수 있게 하는 조작

# 메모리 공간에서의 Thread

- 각각의 Process는 독립적인 stack, heap, code, data 영역을 가짐

- Thrad는 stack을 제외한 메모리 영역을 공유

  - IPC없이 Thread간 통신 가능(data,head 공유)

  - 컨텍스트 스위칭 때문에 발생하는 오버헤드가 Process에 비해 작다

## Thread 장단점


| 장점 | 단점 |
| --- | --- |
| 응답성 향상 | 안정성(멀티 프로세스, 멀티 스레드)하나의 프로세스의 스레드 문제시 프로세스에 영향 |
| 손쉬운 자원 공유(process 들의 자원과 메모리 공유) | 동기화 이슈(공유된 자원 동기화 문제) |
| 경제성자신이 속한 process의 지원을 공유Thread 생성, Context Switch가 경제적(process 보다) | 난해한 프로그래밍 기술멀티 프로세스에 비해 흐름 이해와 결과 예측이 어려움어떤 Thread에 문제가 발생했는지 확인이 어려움 |


# Thread 생성과 실행

## Thread 클래스로부터 직접 생성(Runnable interface)

- Thread를 사용하기 위해서는 Thread에 의해 실행될 코드를 작성 - task

- Runnable 인터페이스를 구현하여 인자 없는 run() 메소드를 구현(첫 번째 방법)

- Runnable 구현 클래스 작성
```java
java
  class Task implemtns Runnable {
    public void run() {
      // Thread 실행 코드
    }
  }

  class a {
    public static voia main(String[] args) {
      // main
      Runnable task = new Task();

      Thread thread = new Thread(task); // Runnable task를 매개값으로 Thread 생성자 호출
      thread.start();
    }
  }
```

- 익명 구현 객체로 구현
```java
java
  Thread thread = new Thread(new Runnable(){
    public void run() {
      // Thread 실행 코드
    }
  });
  thread.start();
```

- Runnable interface는 run() 메소드 하나만 정의됨. 람다식으로 변환 가능
```java
java
  Thread thread = new Thread(() -> {
    // Thread 실행 코드
  });
  thread.start();
```

## Thread 하위 클래스로부터 생성

- Thread 클래스를 상속한 후 run 메소드를 재정의

- Thread 클래스로 작업하는 것은 주의하지 않으면 지루하고도 오류가 발생하기 쉽다.

- Thread 클래스를 상속받아 Thread 구현(두 번째 방법)

- 정의
```java
java
  publc class WorkerThrea extends Thread {
    @Override
    public void run() {
      // 스레드가 실행할 코드
    }
  }

  Thread thread = new WorkerThread();
```

- Thread 익명 객체로 코드 변환
```java
java
  Thread thread = new Thread() {
    public void run() {
      // 스레드가 실행할 코드
    }
  }
```

- Thread 이름 설정
```java
java
  thread.setName("스레드 이름");

  thread.getName();
```
```java
java
  // Thread에 의해 실행될 task() 정의 (Runnable interface type)
  Runnable task = () -> {
    String threadName = Thread.currentThread().getName();
    System.out.println("Hello " + threadName);
  };

  task.run();

  // Thread 클래스로부터 직접 생성
  Thread thread = new Thread(task);
  thread.start();

  System.out.println("Done!");
```

# 스레드 우선순위

- 멀티 스레드는 동시성(Concurrency) 또는 병렬성(Parallelism) 으로 실행됨

  - 동시성 : 멀티 작업을 위해 하나의 코어에서 멀티 스레드가 번갈아 가면 실행

  - 병렬성 : 멀티 작업을 위해 멀티 코어에서 개별 스레드를 동시에 실행

- 스레드의 개수가 코어의 수보다 많을 경우, 스레드를 어떤 순서에 의해 동시성으로 실행할 것인가를 결정 : 스레드 스케줄링

- 자바의 스레드 스케줄링은 우선순위(Priority) 방식과 순환 할당(Round-Robin) 방식 사용

  - 우선순위 방식 : 우선 순위가 높은 스레드가 실행 상태를 더 많이 가지도록 스케줄링 → 코드 제어 가능

  - 순환 할당 : 시간 할당량을 정해서 스레드마다 정해진 시간만큼 교대로 수행 → jvm에 의해 결정

- 자바의 우선순위 설정
```java
java
  thread.setPriority(우선순위);

  thread.setPriority(Thread.MAX_PRIORITY); // 10
  thread.setPriority(Thread.NORM_PRIORITY); // 5
  thread.setPriority(Thread.MIN_PRIORITY);  // 1
```

- 우선 순위 샘플 예제
```java
java
  public class CalcThread extends Thread {
    public CalcThread(String name) {
      setName(name);
    }

    public void run() {
      for(int i = 0; i < 2000000; i++){
      }
      System.out.println(getName());
    }
  }

  public class PriorityExample {
    public static void main(String[] args) {

      for(int i = 1; i <= 10; i++) {
        Thread thread = new CalcThread("thread" + i);
        if(i != 10) {
          thread.setPriority(Thread.MIN_PRIORITY);
        } else {
          thread.setPriority(Thread.MAX_PRIORITY);
        }
        thread.start();
      }
    }
  }
```
