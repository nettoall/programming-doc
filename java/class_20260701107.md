# 클래스, 객체

## 클래스
- 객체의 상태를 나타내는 인스턴스 변수
- 초기화 블록 선언
```java
java
	public class Employee() {
		private String name = "";
		private int id;

		// 초기화 블록
		{
			Random generator = new Random();
			id = 1 + generator.nextInt(1_000_000);
		}
	}
```

- 객체에 있는 메서드를 호출할 때는 해당 객체를 this로 접근할 수 있다. 
	```java
	public class Employee {
		private String name;
		private double salary;
	
		public void raiseSalary(double byPercent) {
			double raise = this.salary * byPercent / 100;
			this.salary += raise;
		}
		
		public void setSalary(double salary) {
			this.salary = salary;
		}
	}
	```
- java에서 static으로 선언하지 않은 메서드는 모두 인스턴스 메서드라 함
- 간단 용어 정리: setSalary 에서 salary를 지역 변수, this가 붙은 salary를 인스턴스 변수가 구분

- 메서드가 객체를 전달하면 해당 메서드가 객체 참조의 사본을 얻음
	``` java
	public class Evilmanager {
		private Random generator;
		
		/**
			Employee 객체 참조를 얻음 
		**/
		public void giveRandomRaise(Employee e) {
			double percentage = 10 * generator.nextGaussian();
			e.raisealary(percentage); // e는 객체 참조의 사본 
		}
	}
	```

- ‼️기본 타입(primitive) 파라미터를 업데이트 하는 메서드를 작성 못함
	```java
	public void increaseRandomly(double x) {
		double amount = x * generator.nextDouble();
		x += amount; // primitive 지역 변수를 업데이트 하지 못함.
	}
	```

- ‼️객체 참조를 다른 것으로 변경하는 메서드도 작성할 수 없다.
	```java
	public void replacewithZombie(Employee e) {
		e = new Employee("", 0); // 값이 변경되지 않음
	}
	```

## 객체
- 호출 대상 객체를 변경하는 메서드를 변경자(mutator)
- 객체를 변경하지 않는 메서드를 접근자(accessor)
- 변수는 객체에 대한 참조만 담음

### 오버 로딩
- 생성자는 두 가지 이상의 다른 버전으로 제공
- 생성자를 오버로드(중복 정의) 가능

### 인스턴스 변수 초기화
- 인스턴스 변수 초기화는 객체가 할당되고 생성자가 실행되기 전에 발생
- 초기화 말고 클래스 선언부에 이의의 초기화 블록을 포함하여 정의 가능
```java
public class Employee() {
	private String = "";
	private int id;
	private double salary;
	
	{. // 초기화 블록
		Random generator = new Random();
		id = 1 + generator.nextInt(1_000_000);
	}
	
	public Employee(String name, double salary) {
	
	}
}
```

### 최종 인스턴스 변수
- final로 선언된 변수를 반드시 모든 생성자가 작업을 마치기 전에 초기화 해야 함.
- 초기화한 후에 final로 선언된 변수를 다시 수정할 수 없음.
- ⚠️ 변경 가능한 객체에 참조를 사용하면 final 제어자는 그저 해당 참조가 절대 변하지 않는다는 사실만 나타냄. 객체를 변경하는 일은 가능
	```java
	public class Person {
		private final ArrayList<Person> friends = new ArrayList<>();
		// friends에 값을 추가,삭제 등 변경은 가능
		// friends = 다른 ArrayList로 변경은 불가능 
	}
	```

### 정적 변수와 정적 메서드
- 클래스 안에 있는 변수를 static으로 선언하면 해당 변수는 클래스당 하나만 있게 됨.
	```java
	public class Employee {
		private static int lastId = 0;
		private int id;
		
		public Employee() {
			lastId++;
			id = lastId;
		}
	}
	```
- 클래스를 생성할 때마다 각 객체는 고유의 id를 가지게 됨
- ‼️ 여러 스레드가 Employee 객체를 동시에 생성하면 이 코드를 정상 동작하지 않음 -> 병행 프로그래밍 참고

### 정적 상수
- 특정 클래스의 기능이나 반복 생성해서 호출해야 하는 경우 정적 상수로 선언하는 것을 고려
	```java
	public class Math {
		public static final double PI = 3.1415926535;
		
		private static final Random generator = new Random();
	}
	```

### 정적 초기화 블록
- 초기화 작업이 추가로 필요할 때 정적 초기화 블록 선언
	```java
	public class CreditCardForm {
		static {
			int year = LocalDate.now().getYear();
			for ( int i = year; i <= year + 20; i++) {
				expriationYear.add(i);
			}
		}
	}
	```
- 모든 정적 변수 초기화와 정적 초기화 블록은 클래스 선언부에 나타난 순서로 실행

### 정적 메서드
- 정적 메서드 정의 요구 사항
	1. 정적 메서드는 객체로 동작하지 않음 -> primitive 타입은 클래스가 아니므로 primitive 타입의 인스턴스 메서드를 호출하기 위해서는 해당 객체를 생성하여 호출해야 함. => 객체를 생성하지 않고 primitive 타입의 메서드를 호출하기 위해 정적 메서드로 정의 
	2. 다른 사람이 만든 클래스에 부가 기능을 제공 
		- ex: Random.nextInt(), LocalDate.now() 

### 팩토리 메서드
- 정적 메서드는 흔히 팩토리 메서드를 만드는 데 사용
- 클래스의 새로운 인스턴스를 반환하는 정적 메서드
	```java
	NumberFormat currencyFormatter = NumberFormat.getCurrencyInstance();
	NumberFormat percentFormatter = NumberFormat.getPercentInstance();
	```

#### 팩토리 메서드를 정의하는 이유
1.  일반적으로 생성자를 구별하는 방법은 생성자의 파라미터 타입이며 인자없는 생성자는 두 개씩 둘 수 없음.
	```java
	public class Employee {
	    /**
		    두 개의 인자 없는 생성자 정의 불가
	    **/
		public Employee() {
		
		}
		
		public Employee() {
		
		}
	}
	```
2. new NumberFormat(...) 은 NumberFormat 객체를 반환해 줌. 팩토리 메서드는 서브 클래스의 객체를 반환할 수 있음.
	```java
	NumberFormat format1 = new NumberFormat(); // NumberFormat 객체를 반환
	
	NumberFormat currencyFormatter = NumberFormat.getCurrencyInstance(); //DecimalFormat 객체 반환. NumberFormat의 서브 클래스임.
	```
1. 팩토리 메서드를 사용하면 불필요하게 새 객체를 생성하는 대신 공유 객체를 반환하는 것도 가능
```java
List list = Collections.emptyList();  //빈 리스트 반환(공유 객체)
```
