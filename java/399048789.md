## Byte 기반 스트림과 문자기반 스트림
- Byte 기반 스트림 (InputStream/OutputStream)
  - 그림,멀티미디어,문자 등 모든 종류의 데이터 I/O
- 문자 기반 스트림(Reader/Writer)

  - DataInputStrea, DataOutputStream, BufferedReader, BufferedWriter

## Scanner
- 표준 입력 스트림 System.in 패키지. 바이트 한 개만 입력 가능
- 문자열과 숫자를 읽으려면 java.util.Scanner 필요
```java

	Scanner in = new Scanner(System.in);
	String name = in.nextLine(); // 한 라인 읽기
	String firstName = in.next(); // 공백으로 구분된 한 단어 읽기
	int age = in.nextInt(); // 정수 읽기
```

## Console
- Scanner가 비밀번호 등의 보안에 취약하므로 Console을 사용하여 처리
```java

	Console terminal = System.console();
	String username = terminal.readLine("User name: ");
	char[] passwd = terminal.readPassword("Password: ");
```
:exclamation: 파일에서 입력을 받거나 출력할 시 쉘의 재지정 문법을 사용
```text
java mypackage.MainClass < input.txt > output.txt
```

## 서식 지정 출력
- System.out.printf 사용 시 서식 지정 출력용 변환 문자 
 
|변환 문자| 목적 | 예|
|-----------|------|----|
|d|정수|159|
|x 또는 X| 16진수| 9f 또는 9F|
|o| 8진수|237|
|f|고정 부동소수점|15.9|
|e 또는 E| 지수 부동소수점| 1.59e+01 또는 1.59E+01|
|g 또는 G| 일반 부동소수점: e/E와 f/F 중 짧은 형태|-|
|a 또는 A| 16진 부동소수점| 0x1.fccdp3 또는 0X1.FCCDP3|
|s 또는 S|문자열| java 또는 JAVA|
|c 또는 C|문자|j 또는 J|
|b 또는 B| boolean| false 또는 FALSE|
|h 또는 H|hash 코드|42628b2 또는 42628B2|
|t 또는 T|날짜와 시간(deprecated됨)|-|
|%|퍼센트(백분율) 기호|%|
|n|플랫폼별 줄 분리자|-|

- 예제
```java

	System.out.printf("Hello, %s. Next year, you';; be $d.\n", name, age);
```

- 서식 지정 출력의 패턴을 제어하는 플래그

|플래그|목적|예|
|-------|-----|---|
|+|양수와 음수의 부호를 출력|+3333.33|
|빈칸|양수 앞에 빈칸 추가| \_3333.33|
|-|필드를 왼쪽 정렬|3333.33|

|(|음수 값을 괄호로 감쌈|(3333.33)|
|,|그룹 분리자 사용|3,3333.33|
|#(f 서식)|항상 소수점 포함|3333.|
|#(x 또는 o 서식)|접두어 0X 또는 0 추가|0xcafe|
|$|서식을 지정할 인자의 인덱스를 지정| 159 9f|
|<|앞의 명세와 같은 값의 서식을 지정| 159 9f|
