	```java
	/**
	```

- 일반 주석
	- @since : 해당 기능을 이용할 수 있는 버전 정보등 기입 가능
	- @deprecated : 해당 기능을 사용하지 말아야 한다는 주석
		- @deprecated Use \<code>setVisible(true)\</code> instead
- 링크
	- @see : javadoc 관련 부분
		- 클래스를 메서드나 변수 이름과 구분할 때 # 사용
		- "" 안의 텍스트가 참고 섹션에 표시됨
	- @link: 외부 문서에 대한 하이퍼 링크 
		- {@link 패키지.클래스#특징레이블}
