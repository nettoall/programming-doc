# Programming : CSS

Created by Dongwook Han, last modified on 4월 13, 2022

## 사용법

- \<style\>\</style\> 정의
- 각 태그별 property 설정
  - \<a href=”” style=”color:red;”/\>

## \<style\> 정의
```yaml
a {             //Selector
    color:red;  // Declaration
    }           // Property Value
```

## CSS속성 정의
```yaml
<style>
 a {
    color:black;
    text-decoration: none;
    }
  h1 {
    font-size:45px;
    text-align:center;  
  }
</style>
```

## CSS선택자
```yaml
<html>
<head>
<style>
a {
    color:black;
    text-decoration: none;
    }
    .saw {
     color:gray;
    }
    //.active {
    //  color:red;
    //}
    #active {
      color:red;
    }
  h1 {
    font-size:45px;
    text-align:center;  
  }
</style>
</head>
<body>
 <h1<a href="README.md">WEB</a></h1>
 <ol>
  <li><a href="1.md" class="saw">HTML</a></li>
  <li><a href="2.md" class="saw active" id="active">CSS</a></li>
  <li><a href="3.md">JavaScript</a></li>
 </ol>
</body>
</html>
```

- 선택자를 지정하여 css 적용하기 위해 “.saw” class를 추가하여 지정- class=”saw active” 두 개를 정의시 style 선언 순서에 따라 적용이 됨.- 우선 순위가 높은 선택자를 사용하기 위해 id 선언. saw선언보다 뒤에 있어도 적용됨(id 선택자가 class선택자보다 우선함) id \> class \> tag

Block
- style 로 지정하는 각 항목별로 자기만의 block 크기를 가진다.
- h1 tag는 해당 문구의 화면을 커버하나 a tag는 해당 문자 만을 커버한다.
```yaml
<style>
/* 각 태그별 정의 */
h1 {
   border-width:5px;
   border-style:solid;
   border-color:red;
}
a{
   border-width:5px;
   border-style:solid;
   border-color:red;
}
/* 중복항목 제거 및 재정의 */
h1, a {
  border:5px solid red;
}
</style>
```
Box Model
- css 의 디자인 및 레이아웃![](attachments/352387114/352452731.png)

 }
