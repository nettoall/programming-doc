## 사용법
- \<style\>\</style\> 정의
- CSS 문법
	- Selector: "h1"
	- Property: "color"
	- Value: "yellow"
	- declaration: "color:yellow, font-size:2em;"
	- declaration block: "{color: yellow, font-size:2em;}"
	- rule set: "h1 { color: yellow, font-size:2em;}"
		```css
		h1 { color: yellow, font-sise: 2em;}
		```
- 각 태그별 property 설정
  - \<a href=”” style=”color:red;”/\>

## \<style\> 정의
```yaml
a {             //Selector
    color:red;  // Declaration
    }           // Property Value
```

## CSS속성 정의
```yaml
<style>
 a {
    color:black;
    text-decoration: none;
    }
  h1 {
    font-size:45px;
    text-align:center;  
  }
</style>
```

### class 선택자
- 요소(html태그)에 구애받지 않고 스타일 규칙을 적용할 수 있는 방법(동일한 태그라도 개별적으로 스타일 적용)
- class속성은 글로벌 속성이므로 어느 태그에서도 사용 가능(정의 앞에 .을 찍어서 clsss 선택자 구분)
- 예
	```css
	.foo{font-size:30px;}
	```
- html 적용 예
	```html
	<p class="foo">...</p>
	```

#### 다중 class
- html 태그를 하나의 class 값이 아닌 여러 개의 class값을 가짐
- css 예
	``` css
	.foo { font-size:30px;}
	.bar { color:blue;}
	```
- html 예
	```html
	<p class="foo bar">...</p>
	```

### 속성 선택자
- 단순 속성으로 선택
- 정의의 실제 value에 상관없이 같은 규칙이면 적용됨
- css 예
	```css
	p[class] {color:silver;}
	p[class][id] {text-decorator:underline;}
	```
- html 예
	```html
	<p class="foor">Hello</p>
	<p class="bar">CSS</p>
	<p class="bar" id="title">HTML</p>
	```

- html 예의 모든 태그가 p\[clsss]의 규칙에 맞기 때문에 세 태그 모두 적용됨
- 마지막 태그만 p\[class]\[id] 규칙 적용

#### 정확한 속성값 선택
- 선택자의 정의에 속성 이름과 속성 값을 정의
	```css
	p[class="foo"] {color:silver;}
	p[id="title"]{text-decorator:underline;}
	```

#### 부분 속성값 선택
- 속성 이름과 속성값 사이테 사용되는 기호에 따라 적용이 다름
	- \[class~="bar"]: class 속성값이 공백으로 구분된 "bar" 단어가 포함되는 요소 선택
	- \[class^="bar"]: class 속성 값이 "bar"로 시작되는 요소 선택
	- \[class$="bar"]: class 속성 값이 "bar"로 끝나는 요소 선택
	- \[class*="bar"]: class 속성 값이 "bar" 문자가 포함되는 요소 선택
- css 예
	```css
	p[class~="color"]{font-style:italic;}
	p[class^="color"]{font-style:italic;}
	p[class$="color"]{font-style:italic;}
	p[class*="color"]{font-style:italic;}
	```
- html 예
	```html
	<p class="color hot">red</p>
	<p class="cool color">blue</p>
	<p class="colorful nature">rainbow</p>
	```

### 가상 클래스(pseudo class)
- 미리 정의해놓은 상황에 적용되도록 약속된 보이지 않는 크래스 
- 약속된 상황이 되면 브라우저 스스로 클래스를 적용
- 특정 요소에 동적인 변화를 시킬 때(javascript 사용 등) 동적인 변화가 발생했을 때 적용할 class 정의?
- css는 정적인 언어이기 때문에 이런 경우 pseudo class라 정의함(:로 정의함)
	```csss
	:pseudo-class {
		property:value;
	}
	```

#### 문서 구조와 관련된 가상 클래스
- 다음과 같이 사전에 가상 클래스에 대한 스타일을 정의할 수 있음
- css 예
	```css
	li:first-child{color: red;}
	li:last-child{color: blue;}
	```
- html 예(동적인 변화로 생성될 html)
	```html
	<ul>
		<li class="first-child">HTML</li>
		<li>CSS</li>
		<li class="last-child">JS</li>
	```

#### 앵커 요소와 관련된 가상 클래스
- 앵커 요소와 관련된 가상 클래스 :link와 :visited
	- :link: 아직 방문하지 않은 앵커
	- :visited: 이미 방문한 앵커
- css 예
	```css
	a:link { color: blue;}
	a:visited { color: gary;}
	```

#### 사용자 동작과 관련된 가상 클래스
- 주로 \<a>에 많이 쓰임

- css 예

### 가상 요소(pseudo element)
- HTML 코드에 존재하지 않는 구조 요소에 스타일 부여
- 선언은 가상 클래스와 동일하게 : 를 사용하나 CSS3부터 가상 클래스와 구분하기 위해 :: 사용
- 하위 브라우저에서 :: 를 지원하지 않는 문제가 있으므로 : 를 쓸지 고민해야 함
- 정의
	```css
	::pseudo-element {
		property: value;
	}
	```
- 상세한 내용은 링크를 확인[가상 요소](https://developer.mozilla.org/ko/docs/Web/CSS/Reference/Selectors/Pseudo-elements)
- 예제
	```css
	p::before { content:"###";}
	p::after {content:"!!!";}
	p::first-line {...}
	p::last-line {...}
	```
- before와 after는 애초에 내용이 없는 상태로 생성되기 때문에 내용을 넣기 위해 content 사용

### 구체성
- 선택자에는 어떤 규칙이 우선으로 적용되어야 하는지에 대해 정해진 규칙
- 구체성의 값이 클수록 우선적으로 적용
- 0,0,0,0 으로 표현됨
	- 0, 1, 0, 0 : 선택자에 있는 모든 id 속성값
	- 0, 0, 1, 0 : 선택자에 있는 모든 class 속성값, 기타 속성, 가상 클래스
	- 0, 0, 0, 1 : 선택자에 있는 모든 요소, 가상 요소
	- 전체 선택자는 0, 0, 0, 0 을 가짐
	- 예제
		```css
		h1 {...} /* 0,0,0,1 */
		body h1 {...} /* 0,0,0,2 */
		.grape {...} /* 0,0,1,0 */
		*.bright {...} /* 0,0,1,0 */
		p.bright em.dark {...} /* 0,0,2,2 */
		#page {...} /* 0,1,0,0 */
		div#page {...} /* 0,1,0,1 */
		```

#### 인라인 스타일
- 인라인 스타일 구체성
- 스타일시트 예제
	```css
	p#page { color:red;} /* 0,1,0,1 */
	```
- 인라인 스타일 예제
	```html
	<p id="page" style="color:blue">Learn</p> <~-- 1,0,0,0 -->
	```

- 인라인 스타일이 구체성 값이 높기 때문에 스타일 시트보다는 우선적으로 적용됨
#### important
- important 키워드는 별도의 구체성 값을 없지만 모든 구체성을 무시하고 우선 순위를 가짐
- 스타일 시트 예제
	```css
	p#page {color:red !impotant;}
	```
- 인라인 스타일 예제
	```html
	<p id="page" style="color:blue">learn</p>
	```
- important 로 스타일시트에 정의했으므로 스타일 시트가 적용됨

### 상속
- 어떤 스타일 규칙이 특정 요소뿐만 아니라 그 자손 요소까지 적용됨
- 예제
	```css
	h1 {color:gray;}
	```

```html
<h1>Hello, <em>CSS</em></h1>
```
- 위의 예제에서 \<em>도 부모인 \<h1>의 스타일을 상속 받음
- 특정 속성에 대해서는 상속 받지 않음. margin, padding, background, border 등 박스 모델 속성은 상속받지 않음

##### 상속되는 속성의 구체성
```css
*{color:red;}
h1#page {color:gray;}
```

```html
<h1 id="page">Hello, <em>CSS</em></h1>
```
- 전체 선택자의 구체성은 0,0,0,0 이며 id 선택자는 0,1,0,1 임
- 구체성에 의하면 id 선택자의 gray가 적용되어야 하나 전체 선택자 red가 적용됨
- 상속되는 경우 구체성은 아무 의미 없음 

### Cascading
- 스타일 규칙들이 어떠한 기준으로 요소에 적용되는지를 정한 규칙
- 단계적인 규칙에 따라 요소에 적용됨
- 아래와 같이 동일한 요소에 규칙을 정의시 적용될 스타일은 마지막 정의(선언 순서)
	```css
	h1 { color:red;}
	h1 { color:blue;}
	```

#### cascading 규칙
- 다음 3가지 규칙이 있음
	1. 중요도(important) 와 출처
	2. 구체성
	3. 선언 순서
- css출처: 사이트를 제작한 css, 웹페이지 방문하는 일반 사용자 css, 브라우저에 내장된 css 
- 스타일이 적용되는 방식
	1. 스타일 규칙들을 모아서 중요도가 명시적으로 선언되었는지 분류
		1. 중요도가 명시적으로 선언된 규칙들은 그렇지 않은 규칙들보다 우선
		2. 중요도가 있는 규칙들끼리는 아래 다른 규칙들을 적용
	2. 스타일 규칙들을 출처에 따라 분류
		1. 제작자 스타일 규칙이 사용자 에이전트 스타일 규칙보다 우선
	3. 스타일 규칙들을 구체성에 따라 분류
		1. 구체성이 높은 규칙들이 우선
	4. 스타일 규칙들을 선언 순서에 따라 분류
		1. 뒤에 선언된 규칙 우선

## 속성
### 단위
#### 절대 길이
- px
	- 1px = 1/96th of 1 inch
	- 화면에서 고정된 크기를 가지지만 장치의 해상도에 따라 상대적
	- 여러 환경에서 디자인을 같게 표현하고 브라우저 호환성에 유리한 구조
- pt
	- 1pt = 1/72 of 1 inch
	- 인쇄물이나 워드 프로세스 프로그램에서 사용된 가장 작은 표준 인쇄 단위
	- 웹 화면에 인쇄용 문서를 위한 스타일을 적용할 때 유용하게 사용
	- 사용하는 기기의 해상도에 따라 차이가 있어 W3C에서 권장하는 단위 아님
#### 상대 길이
- % : 부모의 값에 대해서 백분율로 환산한 크기
- em : font-size를 기준으로 환산. 소수점 3자리까지 표현 가능
- rem: root의 font-size를 기준으로 값 환산
- vw: viewport의 width값을 기준으로 1%의 값으로 계산됨

### 색상
#### 색상 값 지정 방식
- 컬러 키워드
	- red, blue 같이 미리 정의되어 있는 키워드 사용
- 16진법
	- 예: #RRGGBB
	- 6자리의 16진수는 각각 두자씩 세가지 색상을 나타냄(RGB)
- 16진법
	- 예: #RGB 
	- 6자리의 16진수에서 각각의 두자리가 같은 값을 가지면 3자리로 축약하여 사용 가능
- RGB()
	- RGB값을 rgb(R,G,B)의 형태로 각 변수값의 강도를 정의
	- 0-255의 정수로 된 값을 지정할 수 있음
- RGBA()
	- RGBA의 값을 기존 RGB에서 A값이 추가된 형태
	- A 투명도의 강도를 정의
	- A값을 0 ~ 1 사이의 값을 지정할 수 있으며 소수점으로 표기

### background
- background-color
	- 기본값 : tranparent
	- 배경의 색상을 지정
- background-image
	- 기본값: none
	- 배경으로 사용할 이미지 경로 지정
- background-repeat
	- 기본값: repeat
	- 이미지의 반복 여부와 방향을 지정
		- repeat: x,y 축으로 모두 반복
			- repeat-x: x축 방향으로만 반복
			- repeat-y: y축 방향으로만 반복
			- no-repeat: 이미지 반복하지 않음
- background-position
	- 기본값: 0% 0%
	- 요소에서 배경 이미지의 위치를 지정하는 속성
	- x축, y축으로부터의 위치를 지정
	- 한쪽만 지정된다면 나머지는 중앙 값으로 적용
		- %: 기준으로부터 %만큼 떨어진 지점과 이미지의 %지점이 일치하는 곳에 위치
		- px: 기준으로부터 px만큼 떨어진 지점과 이미지의 (0,0) 지점이 일치하는 곳에 위치
		- 키워드: top, left, right, bottom, center 키워드 사용
- background-attachment
	- 기본값: scroll
	- 화면 스크롤에 따른 배경 이미지의 움직임 여부를 지정
		- scroll: 배경 이미지는 요소 자체를 기준으로 고정되어 있으면 내용과 함께 스크롤 안 됨
		- local: 배경 이미지는 요소의 내용을 기준으로 고정되어 있으며 내용과 함께 스크롤 됨
		- fixed: 배경 이미지는 뷰포트를 기준으로 고정되어 있으며 스크롤레 영향을 받지 않음


### Box Model
- Html의 모든 요소는 사각형의 박스 행텨로 만들어짐
- css 의 디자인 및 레이아웃![](attachments/352387114/352452731.png)
- content : 요소의 실제 내용을 포함하는 영역
- border : content영역을 감싸는 테두리 선
- padding 영역: content영역과 테두리 사이의 여백
- margin: border 바깥쪽의 영역, 다른 요소와 구변하기 위해 쓰이는 빈 영역

```html
<style>
 h1 {
  border:5px solid red;
  padding:20px;
  margin:20px;
  display:block;
  width:100px;
 }
</style>
```

## 기타
### vertical-align
- 텍스트틑 수직 정렬
- block(div, p) 요소가 아닌 inline 또는 inline-block에서만 사용
- vertical-align: keyword | length | percent | initial | inherit;
- 기본값 baseline (소문자 x를 기준으로 하단 라인을 의미)

### text-align
- 텍스트를 수평 정렬
- text-align: left | right | center | justify | initial | inherit;

### text-indent
- 새로운 문단의 시작 들여쓰기
- text-indent: length | initial | inherit;
- length : px, em, %

### text-decoration
- 텍스트 꾸밈
- text-decorator: text-decoration-line text-decoration-color text-decoration-style | initial | inherit;
- text-decoration-line: 기본값 none
	- underline : 밑줄
	- overline: 윗줄
	- line-through: 중간선
- text-decoration-style: 선의 스타일
	- solid
	- double
	- dotted
	- dashed
	- wavy

### white-space
- 요소 안에 공백 처리
- white-space: normal | nowrap | pre | pre-line | pre-wrap | initial | inherit;
	- normal: 공백과 개행을 무시하고 필요한 경우 자동 줄바꿈 발생
	- nowrap: 공백과 개행을 무시하고 자동 줄바꿈이 일어나지 않음
	- pre: 공백과 개행을 표현하고 자동 줄바꿈이 일어나지 않음
	- pre-line: 공백은 무시하고 개행만 표현, 필요한 경우 자동 줄바꿈 발생
	- pre-wrap: 개행은 무시하고 공백만 표현. 필요한 경우 자동 줄바꿈 발생

### letter-spacing
- 자간을 지정하는 속성
- letter-spacing: normal | length | initial | inherit

### word-spacing
- 단어 사이의 간격을 지정하는 속성
- word-spacing: normal | length | initial | inherit;

### word-break
- 단어가 라인 끝에 나올 경우 어떻게 처리할지(중단점) 지정하는 속성
- word-bread: normal | break-all | keep-all | initial | inherit;

### word-wrap
- 요소를 벗어난 단어의 줄바꿈을 지정하는 속성
- word-wrap: normal | break-word| initial | inherid

## CSS 적용
### inline
- 해당 요소에 직접 스타일 속성을 이용해서 규칙 선언
	```css
	<div style="color:red;">내용</div>
	```

### Internal
- 문서에 \<sytle>\</style> 로 정의
	```html
	<style>div { color:red;}</style>
	```

### External
- 외부 스타일 시트 파일 이용(.css 파일)
	```css
	div { 
		color:red;  
	}
	```
- html에 \<link> 를 사용하여 연결
	```html
	<link rel="stylesheet" href="css/style.css">
	```

### Import
- 스타일 시트 내에서 다른 스타일 시트 파일을 불러 오는 방식
- \<style> 내부 상단이나 외부 스타일 시트 파일에 선언하는데 성능상 좋지 않아 거의 쓰이지 않음
	```css
	@import url("css/sytle.css");
	```
