# HTML

## 표의 구조와 관련된 태그
- `<caption>` :  표의 제목을 나타내는 태그
- `<thead>` : 제목 행을 그룹화하는 태그
- `<tfoot>`: 바닥 행을 그룹화하는 태그
- `<tbody>`: 본문 행을 그룹화하는 태그
- 예제
```html
<table>
	<cation>Month Savings</caption>
	<thead>
		<tr>
			<th>Month</th>
			<th>Savings</th>
		</tr>
	</thead>
	<tbody>
		<tr>
			<td>January</td>
			<td>$100</td>
		</tr>
		<tr>
			<td>February</td>
			<td>$80</td>
		</tr>
	</tbody>
	<tfoot>
		<tr>
			<td>Sum</td>
			<td>$180</td>
		</tr>
	</tfoot>
</table>


```

- 표와 관련된 추가 태그
	- `<colgroup>`
	- `<col>`
	- scope 속성
	- header 속성

## form 과 관련된 태그
- `<label>` : form 요소의 이름과 form 요소를 명시적으로 연결
```html
		<label for="name">이름`</label>`:<input type="text" id="name">

		<label for="nickname">별명`</label>`:<input type="text" id="nickname">

```

- `<fieldset>` : 여러 개의 폼 요소를 그룹화하여 구조적으로 만들기 위해 사용
- `<legend>`: 폼 요소의 제목으로 `<fieldset>` 내부에 작성
```html
	<fieldset>
		<legend>기본 정보</legend>
		 폼요소들..
	</fieldset>
	<fieldset>
		<legend>부가 정보</legend>
		 ...
	</fieldset>

```

## 콘텐츠 모델, 시멘틱 마크업, 블록

### Content Models의 7분류
- Metadata Content
- Flow Content
- Sectioning Content
- Heading Content
- Pharasing Content
- Embedded Content
- Interactive Content

#### 1. Metadata
- base, link, meta,, noscript, script,, sytle, title
- Metadata에는 콘텐츠의 스타일, 동작을 설정하거나 다른 문서와의 관계 등 정보를 포함하는 요소
- 메타 태그, 타이틀 태그, 스타일 태그, 링크 태그 등 대부분 \<head> 내에 들어감


#### 2.Flow
- a, abr, address, map, button, br, canvas, cite, code, embed, nav, noscript, 
- Flow 에는 문서의 자연스러운 흐름에 의해 배치되는 요소들이 포함
- Metadata에 해당하는 일부 태그들만 Flow에서 제외되며 요소 대부분이 Flow에 포함됨

#### 3. Sectioning
- article, aside, nav, section
- 문서의 구조와 관련된 요소들이 포함
- HTML5에서 새로 생긴 \<article>, \<aside>, \<nav>, \<section> 등이 포함, 문서의 구조, 아웃라인에 영향을 줌

#### 4. Heading
- h1, h2, h3
- Heading에는 각 section의 header를 정의하는 heading 태그가 포함됨

#### 5. Phrasing
- a, abbr,... 3. Flow에서 나열했던 항목들과 유사 
- 문서의 텍스트 또는 텍스트를 꾸며주는 문단 내부 레벨로 사용되는 요소들이 포함됨

#### 6. Embedded
- audio, canvas, embed, iframe, img, math, object, svg, video
- 외부 콘텐츠를 포현하는 요소들이 포함되며 오디오나 비디오, 이미지 등 멀티미디어 관련 요소들이 해당됨.

#### 7. Interactive
- a, audio\[contorls] button, details, embed, iframe, img\[usemap] ...
- 사용자와 상호작용을 하는 요소들이 포함되며 대표적으로 form요소들이 이에 해당됨
- 

- Content Model  분류는 사용하는 유형에 따라 구분이 되는 것이지 특정 태그를 이건 Heading 이나 Phrasing이다 라고 고정적으로 분류하지는 못함. -> 설명에도 동일한 태그들이 필요에 따라 content model에 반복적으로 들어가 있음.

### 시멘틱 마크업
- POSH(Plain Old Semantic HTML) 라고도 불림. 오래된 의미론적인 HTML
- 기계(컴퓨터, 브라우저)가 잘 이해할 수 있도록 하는 것
- 정해진 규칙에 따라 문서를 구조화해주면 되는 것 
- non semantic : \<div>, \<span>

### 블록
- 부모 요소의 가로 영역에 맞게 꽉 채워져 표현되는 요소
- 양 옆으로 다른 요소가 배치되지 않게 박스를 생성, 박스의 위 아래로 줄 바꿈이 생기게 됨
- 블록 레벨 요소는 일반적인 모든 요소(블록, 인라인 레벨 등)을 포함할 수 있음
- \<div> \<h1>\</h1> \<p>\<ul>\<li>\<table> 
#### 인라인 레벨 요소
- 하나의 라인 안에서 자신의 내용 만큼의 박스를 만드는 요소
- 라인의 흐름을 끊지 않고 요소 앞 뒤로도 줄 바꿈이 되지 않아 다른 인라인 요소들이 자리할 수 있음.
- 인라인 레벨 요소는 블록 레벨 요소의 child로 분류되기 때문에 블록 레벨 요소를 가질 수 없음
