## html style 적용하기

- <div> 화면 전체를 사용하기에 줄바꿈, <span> 줄바꿈 되지 않음
  - 태그 내에 style 속성을 추가하여 특정 부분에만 스타일 적용 (class 로 정의하여 사용)
  - 선택자 class, id, 태그 지정 하기(적용 우선 순위는 id> class > 태그 순)
	```
	<style>
      .js { <!-- class 정의 . 사용 -->
        color:red;
        }
    #first { <!-- id 정의 # 사용 -->
	    color: green;
    }
    span { <!-- 태그 정의 -->
		color: blue;
    }
    </style>
	```
	  
- querySelector를 사용하여 적용
	```
	document.querySelector("body") <!-- 태그 선택 -->
	document.querySelector(".js") <!-- class 선택 -->
	document.querySelector("#first") <!-- id 선택 -->
	```
- 스타일 적용
	``` 
	document.querySelector("body").style.backgroundColor="black";
	```
