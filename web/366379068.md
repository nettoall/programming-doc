``` html
	color:red;

	color: green;

	color: blue;
```


    - 검출하고자 하는 패턴을 만드는 일
    - 정규표현식 객체 만들기
```javascript
      var pattern = /a/ ; // 방법 1
      var pattern = new RegExp('a'); // 방법2

      pattern.exec('abcdef'); // a를 값으로 하는 배열 반환, 없을시 null 반환
      pattern.test('abcdef'); // 있으면 true, 없으면 false
```

- 문자열 메소드
  - match()
    console.log('abcdef'.match(pattern));
  - replace()

  - i : 대소문자 구분 안함

	```javascript
    ”Abcde”.match(oi); // \['A”\]
	```
    
  - g: 검색된 모든 결과 리턴

## Navigator
- 웹 브라우저 버전, 플러그인 설치 정보, 온.오프라인 등의 여러 정보 제공

  - createTextNode() :새로운 텍스트 노드를 만듬
  - appendChild() : 텍스트 노드를 요소 노드의 자식으로 연결
  - appendChild() : 요소 논드를 DOMㅇ에 연결

- 속성값이 있는 새로운 요소 추가
  - createElement() : 새로운 요소 노드를 추가
  - crerateAttribute() : 새로운 속성 노드를 추가
  - 속성값 지정하기 : 속성값을 프로퍼티로 지정
  - setAttributeNode() : 속성 노드를 요소 노드의 자식으로 연결
  - appendChild() : 요소 노드를 DOM에 연결
