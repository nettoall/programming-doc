# JSTL


| 태그 | 설명 |  |  |
| --- | --- | --- | --- |
| core | 변수 선언, 조건문, 반복문, Url처리 | c | http://java.sun.com/jsp/jstl/core |
| formatting | 숫자,날짜, 시간 포맷 지정 | fmt | http://java.sun.com/jsp/jstl/fmt |
| XML | XML파싱 | x | http://java.sun.com/jsp/jstl/xml |
| Function | 컬랙션, 문자열처리 | fn | http://java.sun.com/jsp/jstl/functions |
| SQL | 데이터베이스 연결, 쿼리 실행 | sql | - http://java.sun.com/jsp/jstl/sql |


- SQL, Function 잘 사용하지 않음

- 사전 조건

  - JSTL을 사용하기 위해서는 JSP파일에서 taglib 지시어 추가 필요
```text
text
    <%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core"%>
```

- jstl-1.2.jar library 추가
