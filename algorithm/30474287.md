# 세 값이 대소 관계와 중앙값

예제
```java
class Median{
  static int med3(int a, int b, int c){
    if(a>= b){
      if(b >= c){
        return b;  //A,B,F,G
      }else if(A <= c){
        return a;  //D,E,H
      }else{
        return c;  //c
      }
    }else if(a > c){
      return a;   //I
    }else if(b > c){
      return c;  //J,K
    }else{
      return b;  //L,M
    }
  }
}
```
