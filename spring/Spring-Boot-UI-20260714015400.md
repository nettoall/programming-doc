- Board Entity class
	```java
	@Getter
	@Setter
	@ToString
	@Entity
	public class Board {
		@Id @GeneratedValue
		private Long seq;
		
		private String title;
		
		@Column(updatable=false)
		private String writer;
		
		private String content;
		
		// sysdate 속성은 deprecated된 듯, current_date 로 변경
		@Column(insertable=false, updatable=false, columnDefinition="date default sysdate")
		private Date createDate;
		
		@Column(insertable=false, updatable=false, columnDefinition="number default 0")
		private Long cnt;
	}
	```
	- @Column 의 속성에 updatable 을 사용해서 UPDATE 시 컬럼 제외 설정할 수 있음(updatable=false)
	- @Column 속성에 insertable을 사용하여 INSERT 시 컬럼 제외 설정할 수 있음(insertable=false)
	- columnDefinition 속성에서 날짜 date default sysdate 설정이 가능했지만 현재 사용 못함. sysdate 대신 current_date로 변경됨

			Member findMember = memberService.getMember(member);
			
			if (findMember != null && findMember.getPassword().equals(member.getPassword()) {

	}

### 예외처리
- Spring 예외처리
	1. @ControllerAdvice  사용해서 모든 controller에서 발생하는 예외를 일괄 처리 : 전역 예외 처리
	2. @ExceptionHandler 를 사용해서 각 controller마다 발생하는 예외를 개별 처리 : 로컬 예외 처리
- 자바에서의 예외
	- Checked Exception : 컴파일 시점에 발생하는 예외
	- Unchecked Exception:  실행 시점에 발생하는 예외

#### 전역 예외 처리
- 사용자 정의 예외 생성 : 예)  BoardException
- 예외 처리기 구현
	```java
	@ControllerAdvice
	public class GlobalExceptionHandler {
	
		/**
		 * 발생한 Exception 유형에 따라 처리하도록 메서드 정의
		 */
		@ExceptionHandler(BoardException.class)
		public String handleCustomException(BoardException exception, 
		                                      Model model) {
			model.addAttribute("exception" , exception);
			return "/errors/boardError";                                      
		}
		
		@ExceptionHandler(Exception.class)
		public String handleException(Exception exception, Model model) {
			model.addAttribte("exception", exception);
			return "/errors/globalError";
		}
	}
	```
	- 각 기능마다 정의한 boardError.html, globalError.html 정의
