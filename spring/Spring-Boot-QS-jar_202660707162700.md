
# 독립적으로 실행 가능한 JAR

## 패키징 구조
- maven install, gradle build 후 생성된 jar 구조
```directory
BOOT-INF
 ┣━ BOOT-INF
 ┃  ┣━ classes
 ┃  ┗━ lib
 ┣━ META-INF
 ┃  ┗━ maven
 ┗━ org
    ┗━ springframework
```

- BOOT-INF : classes와 lib 폴더로 구성
	- classes : 소스 컴파일 클래스
	- lib: dependency library
- META-INF: 애플리케이션 메타 데이터 저장된 매니페스트 파일 존재

### Spring boot loader
- 기본적으로 Jar파일은 또 다른 Jar파일을 포함할 수 없음
- 또 다른 Jar 파일 내의 클래스를 포함하고 싶다면 압축을 해제하고 병합하여 새로운 Jar로 압축해야 함.
- Spring Boot는 패키징된 Jar 파일 안에 있는 또 다른 Jar파일을 읽어서 로딩하는 유틸리티 클래스 제공
	- org/springframework.boot/loader/jar 에 위치 JarFile 로더 클래스
	- main() 메소드를 포함한 클래스를 실행하기 위해 org.springframework.boot/loader JarLauncher 클래스
