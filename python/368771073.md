## 함수

자주 사용하는 로직 정의

### 함수 구조 정의
```python
def 함수이름(매개변수):
  수행할 문장1
  수행할 문장2
```

#### 예제
```python
def add(a,b):
  return a+b
```

### 매개변수와 인수- parameter : 함수에 입력으로 정의된 변수- argument : 함수에 전달되는 입력값
```bash
python
  def add(a, b):    # a,b 매개변수
    return a + b

  print(add(3,4))  ## 3,4 인수
```

### 함수의 형태

자바와는 다르게 parameter, return 값의 type을 정의 안 함

- 파이썬은 매개변수 순서에 상관없이 전달 가능(매개변수를 지정하여 값 설정 시)
```python
properties
  result = add(b=5, a=3)
```

- parameter가 여러 개인 경우 선언(매개변수에 \* 정의 : \*args)
```bash
python
  def add_many(*args):
    result = 0;
    for i in args
      result = result + i
    return result

  add_many(1,2,3,4,5,6,7)
```

- 함수 선언
```bash
python
  def add_mul(choice, *args) # 매개변수 선언
    if choice = "add":
```

## 키워드 파라미터 (\*\*)
```python
def print_kwargs(**kwargs):
  print(kwargs)
```

- \*\*를 붙이면 kwargs는 딕셔너리가 됨
```python
print_kwargs(a=1)
    {'a}:1}
  print_kwargs(nam='foo',age=3)
    {'age':3,'nam':'foo'}
```

### 함수의 결괏값

함수 내 return 하는 값을 여러 개 정의 시 튜플 형태로 결괏값을 반환함(결괏값은 튜플 자료형 하나임)
- 함수 선언

```python
def add_and_mul(a,b):
    return a+b, a*b   # 반환 두개 정의
```

- 예제
```python
>>> result = add_and_mul(3,4)
  result = (7,12) # 튜플 형식으로 리턴됨
  # 두개의 결과값으로 받으려면
  >>> result1,result2 = add_and_mul(3,4)
  result1 = 7
  result2 = 12
```

def say_myself(name, old, man=true) # man=True는 초기값 설정

say_myself("박한돌",27)

### 함수안에서 선언한 변수 범위

- 함수안 변수의 범위
```python
a = 1
  def vartest(a):
    a = a + 1 # a는 함수밖의 a와 별개 변수

  vartest(a)
  print(a)
```

- 함수밖 변수 변경하기
  1.  return사용
```python
a = 1
      def vartest(a):
         a = a + 1
         return a

      a = vartest(a)
```

  2.  글로벌 변수 선언
```python
a = 1
      def vartest():
        global a # 함수밖의 a를 사용한다는 선언
        a = a + 1

      vartest()
```

### print()
- ““ 로 둘러 싸인 문자열은 + 연산과 동일
- 문자열 띄어쓰기는 , 로 함
- 한 줄에 결괏값 출력하기 위해서는 매개변수 end 를 사용해 끝 문자 지정
- 사용방법
```python
print("출력")
  print("출력","은","왕이다.") # ,띄어쓰기
  print(i, end= ' ') # 한줄로 이어쓰기
```

## 파일 읽기 쓰기

### 파일 생성

- 사용법
```python
f = open("새파일.txt",'w') # 파일열기 모드 r,w,a
  f.close()
```

- 디렉토리 지정 파일 생성
```python
f = open("C:/doit/새파일.txt",'w')
  f.close() #
```
  - f.close() : 프로그램 종료시 자동으로 파일 받음
  - 파일열기모드 w : 쓰기, r : 읽기, a : 추가
  - 쓰기 모드로 연 파일을 다른 모드로 사용할 시에는 오류가 발생하므로 사용하고 난 뒤 f.close()를 선언하여 닫아 주는게 좋음

- 파일에 저장하기
```python
f = open("C:/doit/새파일.txt",'w')
  for i in range(1,11):
    data = "%d번째 줄입니다.\n" % i
    f.write(data)
  f.close()
```

### 파일 읽기

- 사용법 예제
```python
f = open("C:\doti\읽을파일.txt",'r')
  line = f.readLine() #첫번째 줄만 읽음
  priint(line)
  f.close()
```

- 여러 줄 읽기
  1.  readLine()
```python
while True:
        line = f.readLine() # 더 이상 읽을 값이 없으면 None출력
        if not line: break
```

  2.  readLines()
```python
lines = f.readLines()
      for line in lines
        print(line)
      f.close()
```

  3.  read()
```python
data = f.read() #파일의 내용 전체를 문자열로 돌려줌
      print(data)
```

- 파일에 새로운 내용 추가
```python
f = open("C:/doti/기본파일.txt",'a') # a로 정의
  for i in range(11,20):
    data = "%d 줄입니다.\n" % i
    f.write(data)
  f.close()
```

- 파일 열고 닫기 자동처리
```python
with open("foo.txt","w") as f:
    f.write("....") # 첫번째 라인부터 여기까지 with block 
    # with Block을 벗어나는 순간 f가 자동으로 close()
```
