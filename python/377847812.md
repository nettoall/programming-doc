## ![22](../media/images/icons/emoticons/72/2705.png) 숫자형
- 정수 : 123, -345.0
- 실수 : 123.45, -1234.5, 3.4e10
- 8진수 : 0o34, 0o24
- 16진수 : 0x2A, 0xFF
  - Octal, x : Hexadecimal

### 사용예제
```python
# 정수형
>>> a = 123
>>> a = -178
# 실수형
>>> a = 1.2
>>> a = -3.45
# 8진수(0o로 시작)
>>> a = 0o177
# 16진수(0x로 시작)
>>> a= 0x8ff
```

- 지수 표현 가능 : e나 E 사용한 10의 지수 표현- 유효숫자e지수 = 유효숫자 \* 10 지수- 실수형 : 컴퓨터가 실수값을 정확히 표현 못함 → round() 등 함수로 근사치 계산하여 처리
```yaml

  print(a)
```

### format 심화

- format 코드를 숫자와 같이 사용하면 정렬이나 공백을 나타낼 수 있음
- 정렬, 공백
  - “%10s” % “hi” : 전체 길이 10 문자열 오른쪽 정렬, 나머지 공간 공백 처리
```bash
python
    >>> "%10s" % "hi"
    '        hi'  # 전체 길이 10문자열, hi 앞 공백 8자리
    >>> "%-10sJane" % "hi"
    'hi        Jane'
    # hi가 Jane보다 왼쪽에 공백 8자리. hi부터 jane까지 10자리
```

- 소숫점 표현
  - %0.소수점포인트 숫자 개수 (%0.4f : 소수점 이하 4자리수)
```bash
python
    >>> "%0.4f" % 3.42134234. # 소수자리 4자리까지 출력
    3.4213
    >>> "%10.4f" % 3.42134234
        3.4213
```

### format함수 사용(.format())

- 대체
```python
>>> "I eat {0} apples".format(3)
'I eat 3 apples'
>>> "I eat {0} apples".format("five")
'I eat five apples'
>>> number = 3
>>> "I eat {0} apples".format(number)
'I eat 3 apples'
>>> number = 10
>>> day = "three"
# 2개 이상의 값 넣기
>>> "I ate {0} apples. so I was sick for {1} days".format(number,day)
'I ate 10 apples. so I was sick for three days.'
# 이름으로 넣기
>>> "I ate {number} apples. so I was sick for {day} days".format(number=10, day=3)
'I ate 10 apples. so I was sick for 3 days'
# 인덱스와 이름 혼용하기
>>> "I ate {0} apples. so I was sick for {day} days".format(10, day=3)
'I ate 10 apples. so I was sick for 3 days.'
```

- 정렬
```python
>>> "{0:<10}".format("hi")
  # 출력결과 'hi          '
  >>> "{0:>10}".format("hi")
  # 출력결과 '          hi'
  >>> "{0:^10}".format("hi")
  # 출력결과 '     hi     '
```

- 공백 채우기
```python
>>> "{0:=^10}".format("hi")
  # 출력 결과 '====hi===='
  >>> "{0:!<10}".format("hi")
  # 출력 결과 'hi!!!!!!!!'
```

- format 구조
  - {:} : 앞에 대치할 인덱스 or name, 뒤에 format 자리수, 정렬 형식
```python
>>> y = 3.42134234
    >>> "{0:0.4f}".format(y)
    '3.4213'
    >>> "{0:10.4f}".format(y)
    '         3.4213'  # 공백 9자리
    >>> "{{and}}".format()  # 문자 표현하기
    # 출력 결과 : {and}
```

### 인덱싱

### Slicing

문자열에서 사용하는 방법과 동일 \[시작:끝\]
- case 1 (앞에 정의한 case 1 리스트)
```python
>>> a = [1,2,3]
  >>> a[0:2]
  [1,2]
```

- case 2
```python
>>> a = [1,2,3,['a','b','c']]
  >>> a[2:4] 
  [3,['a','b',c]]
  >>> a[3][0:2]
  ['a','b']
```
