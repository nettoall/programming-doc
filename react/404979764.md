## 사용자 정의 태그 만들기

- 샘플 예제(App.js)
```bash
python
  import logo from './log.svg';
  import './App.css';

  function App() {
    return (


          <h1>[WEB](/)</h1>

        <nav>
          <ol>
- [html](/read/1)
- [css](/read/2)
- [js](/read/3)
          </ol>
        </nav>

          <h2>Welcome</h2>
          Hello, WEB


    );
  }
```

- 위의 예제를 중복되거나 동일한 것들을 그룹으로 정리 =\> 사용자 태그 정의(컴포넌트)

- \<header\>\</header\> → \<Header\> 로, \<article\>\</article\> → \<Article\> 로 function 생성
```bash
python
  import logo from './log.svg';
  import './App.css';

  function Header() {
    return `<header>`
    <h1>[WEB](/)</h1>

  }

  function Article() {
    return `<article>`
    <h2>Welcome</h2>
    Hello, WEB

  }

  function Nav() {
    return <nav>
    <ol>
- [html](/read/1)
- [css](/read/2)
- [js](/read/3)
    </ol>
    </nav>
  }

  function App() {
    return (

        `<Header>`</Header>  // React function 명은 대문자로 시작
        <Nav></Nav>
        `<Article>`</Article>

    );
  }
```
