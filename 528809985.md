# Programming : Spring Boot 3.0 변경시 조치 사항

Created by Dongwook Han on 12월 12, 2025

- RestTemplate

  - httpClient5로 변경

- mybatis version

  - [https://repo.maven.apache.org/maven2/org/mybatis/spring/boot/mybatis-spring-boot/](https://repo.maven.apache.org/maven2/org/mybatis/spring/boot/mybatis-spring-boot/) 에서 맞는 Spring Boot Bersion 확인

- Controller 에서 Service 참조

  - 기존 @Resource("testService") 를 @Autowired 로 변경

  - @Resource 로 정의 시 this.service is null 오류 발생
